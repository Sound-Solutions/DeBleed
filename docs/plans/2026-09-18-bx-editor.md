# DeBleed editor rebuild — Brainworx-style rack (layout A)

**What he gets:** DeBleed's window becomes a landscape panel in the modern Brainworx look:
meter on the left, EXPANDER across the top with THRESH as the big knob, VOCAL and OUTPUT below.
Values sit inside the knobs under a thin glowing arc, the three module switches are ring-LED
buttons named LOOK (1 ms), CLARITY and HARMONIC, and an orange chevron folds the whole knob side
away so only the meter square stays. The meter keeps its spring animation exactly.

Approved mock (his words 2026-09-18: *"Love it"*, then *"No circle around the chevron and make it
orange like the power button and it's good to go"*): `docs/mocks/2026-09-18-bx-editor-approved.html`.
Open it in a browser to see both states with the animated meter; the numbers below are copied from it.

  radial `#2C2C2C` centre → `#1A1A1A` edge, 1 px `#0A0A0A` rim, faint white 5 % inner ring. Pointer
  tick 1.6 px in the section colour from r−11 to r−7.5 at the value angle. Value text centred in the
  disc: 11 px (14 px on the big knob), `#EDEDED`, weight 500, the number only ("-40.0", "4.0", "100").
- **Label under knob:** 8 px bold, letter-spacing 1.2, `#8A8A8A`, uppercase name, then a space and

  "DEPTH dB", "MIX %", "OUTPUT dB"). Buttons: "LOOK 1 ms", "CLARITY", "HARMONIC" (no unit).
- **Ring button:** r 10. Body radial as the knob, 1 px `#0A0A0A` rim, ring stroke 1.8 px in the

- **Chevron:** bare orange path, 1.6 px round caps, 8 px tall, no ring, no disc.
- **Section colours:** EXPANDER orange `#FF9500`, VOCAL green `#39FF14`, OUTPUT cyan `#00D4FF`.
- **Edge title:** 9 px bold, letter-spacing 2.2, `#5E5E5E`, rotated −90°, centred on the section
  height, x = section left + 14.
- **Meter:** track arcs `#282828` 3 px, GR (orange) sweeps left from 12 o'clock, SIGNAL (cyan)
  right, each drawn as a 5 px 35 % glow pass then a 3 px solid. Disc r R−12 with the knob body

- Every grey is pure neutral (r == g == b). The old blue-tinted greys in the editor go.

## Decisions (settled)

- **IDs stay, names change.** Parameter IDs `lookahead` / `consonant` / `comb` / `combDepth` are
  untouched so saved sessions load bit-identically. Display names become "Look", "Clarity",
  "Harmonic", "Harmonic Depth".
- **Collapse is editor state saved with the session**: a non-parameter property `editorCollapsed`
  on the APVTS state tree, so the window reopens the way he left it. Not automatable.
- **The slide** is a 180 ms ease-out-cubic width animation on the editor's own 60 Hz timer calling
  `setSize()` each frame. Sections keep their expanded positions and the window simply reveals or
  covers them; the meter section is always fully visible. If a host resizes with a stutter we still
  land on the exact final size.
- **Values render inside the knob** by hiding the slider text box (`NoTextBox`) and drawing
  `slider.getTextFromValue()` inside `drawRotarySlider`. Text-from-value suffixes are stripped in the
  look-and-feel so only the number shows; the unit lives in the label.
- **Labels are painted, not Label components**: each section paints its titles and knob labels in
  `paint()` on one baseline, two fonts measured with `GlyphArrangement` so name and unit sit on a
  shared baseline. Nothing moves when a value changes.
- **Glow is a two-pass stroke**, never a Gaussian blur per frame.
- **Sections are three `Section` components** (`ExpanderSection`, `VocalSection`, `OutputSection`)
  each owning its sliders/buttons and attachments; `ControlPanel.{h,cpp}` is deleted. The editor
  paints the grooves and owns the meter, name, power button and chevron.
- **Version** bumps to 1.2.0 in the .jucer (editor size changed; Logic must notice), Projucer
  resave, Debug build. The build's copy step installs the AU/VST3 as before.
- **No tests** (layout and styling). The gate is a cold review of the diff by the other model.
